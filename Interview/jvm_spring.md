# Bộ câu hỏi phỏng vấn JVM, Spring và Hibernate — Middle & Senior

> Trọng tâm là khả năng nối cơ chế bên dưới với hành vi production. **[Middle]** cần giải thích đúng và xử lý tình huống quen thuộc; **[Senior]** cần chẩn đoán có bằng chứng, nêu trade-off và thiết kế failure handling.

## 1. Bytecode, class loading và reflection

### JVM-001 [Middle] Từ source Java đến lúc method chạy qua những bước compile, load, link, initialize và execute nào; bytecode mang lại tính portable ra sao?

### JVM-002 [Senior] Mô hình parent delegation của class loader hoạt động thế nào; khi nào custom class loader, plugin container hoặc app server gây `ClassNotFoundException`, `NoClassDefFoundError` hay `ClassCastException` dù tên class giống nhau?

### JVM-003 [Middle] Phân biệt thời điểm load, verify, prepare, resolve và initialize class; truy cập `static final` compile-time constant có kích hoạt initialization không?

### JVM-004 [Senior] Bytecode instruction, operand stack, local variable table và stack frame phối hợp để thực thi method như thế nào; điều này giúp đọc stack trace/decompile ra sao?

### JVM-005 [Senior] Reflection, method handle và generated bytecode/proxy khác nhau về type safety, access check, warmup và hiệu năng; framework nên chọn cách nào?

### JVM-006 [Middle] Annotation có retention/source target khác nhau thế nào; vì sao annotation processor compile time khác reflection runtime?

### JVM-007 [Senior] JPMS module path giải quyết encapsulation/dependency nào so với classpath; split package, automatic module và reflective access gây khó khăn gì?

### JVM-008 [Senior] Hãy chẩn đoán lỗi linkage sau khi nâng version thư viện (`NoSuchMethodError`, `AbstractMethodError`): binary compatibility và dependency convergence liên quan thế nào?

## 2. JIT, memory, GC và diagnostics

### JVM-009 [Middle] Heap, thread stack, metaspace, code cache và direct/native memory chứa gì; loại lỗi cạn bộ nhớ tương ứng được biểu hiện thế nào?

### JVM-010 [Senior] Escape analysis, scalar replacement, inlining và deoptimization của JIT có thể làm benchmark/stack trace khác trực giác ra sao?

### JVM-011 [Middle] Young/old generation và generational hypothesis hoạt động ra sao; allocation, promotion và stop-the-world pause liên hệ thế nào?

### JVM-012 [Senior] So sánh G1, ZGC và Shenandoah theo mục tiêu pause, throughput, heap size và overhead; vì sao không có collector tốt nhất cho mọi workload?

### JVM-013 [Senior] Hãy phân biệt memory leak Java, allocation pressure và native memory leak; dùng heap dump, class histogram, NMT và GC log để xác nhận thế nào?

### JVM-014 [Middle] Strong, soft, weak và phantom reference khác nhau thế nào; vì sao soft reference thường không phải lựa chọn cache production tốt?

### JVM-015 [Senior] GC log cho thấy old-gen tăng dần và full GC không thu hồi: hãy lập kế hoạch điều tra dominator, retained size, GC root và class-loader leak.

### JVM-016 [Senior] Safepoint và stop-the-world khác nhau thế nào; time-to-safepoint dài có thể đến từ đâu và quan sát bằng JFR/log thế nào?

### JVM-017 [Middle] Thread dump cho biết các trạng thái `RUNNABLE`, `BLOCKED`, `WAITING`, `TIMED_WAITING` gì; cách tìm deadlock và lock contention là gì?

### JVM-018 [Senior] Thiết lập observability JVM tối thiểu cho production gồm metric, GC log, JFR, tracing và alert nào; làm sao giữ overhead/chứa dữ liệu nhạy cảm trong kiểm soát?

## 3. Spring IoC, lifecycle, AOP và proxy

### JVM-019 [Middle] IoC/Dependency Injection đem lại lợi ích gì; constructor injection hơn field injection ở điểm nào về invariant, testability và circular dependency?

### JVM-020 [Senior] Spring tạo và khởi tạo bean qua những giai đoạn nào; `BeanFactoryPostProcessor`, `BeanPostProcessor`, init callback và proxy chen vào lifecycle ở đâu?

### JVM-021 [Middle] Scope singleton của Spring có nghĩa gì và có tự thread-safe không; state mutable trong singleton controller/service gây bug nào?

### JVM-022 [Senior] Circular dependency có thể được Spring xử lý hoặc không xử lý trong trường hợp nào; vì sao giải pháp bền vững thường là tách trách nhiệm thay vì dùng `@Lazy`?

### JVM-023 [Middle] JDK dynamic proxy và CGLIB proxy khác nhau thế nào; ảnh hưởng của interface, `final` class/method và self-invocation là gì?

### JVM-024 [Senior] Spring AOP dùng proxy khác AspectJ weaving ra sao; pointcut quá rộng, advice ordering và exception swallowing gây rủi ro production nào?

### JVM-025 [Middle] `@Configuration` full mode và lite mode khác nhau thế nào; gọi trực tiếp một `@Bean` method có luôn trả singleton do container quản lý không?

### JVM-026 [Senior] `@Conditional`, auto-configuration và thứ tự cấu hình của Spring Boot hoạt động ra sao; cách debug vì sao một bean được/không được tạo là gì?

### JVM-027 [Senior] Hãy code review service dùng service locator/ApplicationContext tĩnh: nó che dependency, lifecycle và testability thế nào; lộ trình refactor là gì?

## 4. Transaction và tính nhất quán

### JVM-028 [Middle] `@Transactional` được thực thi qua proxy thế nào; vì sao gọi method nội bộ hoặc tạo object bằng `new` có thể làm annotation không hiệu lực?

### JVM-029 [Senior] Phân biệt propagation `REQUIRED`, `REQUIRES_NEW`, `NESTED` và `MANDATORY`; connection pool và partial commit bị ảnh hưởng thế nào?

### JVM-030 [Middle] Isolation level ngăn dirty read, non-repeatable read và phantom read ra sao; behavior thực tế phụ thuộc database/MVCC thế nào?

### JVM-031 [Senior] Quy tắc rollback mặc định của Spring là gì; catch exception, checked exception hoặc trả failure object có thể vô tình commit ra sao?

### JVM-032 [Senior] Tại sao không nên giữ database transaction trong lúc gọi HTTP/message broker; hãy thiết kế timeout, outbox, idempotency và compensation cho workflow liên dịch vụ.

### JVM-033 [Senior] `@Transactional(readOnly = true)` là hint hay guarantee; nó ảnh hưởng flush, driver/database optimization và correctness thế nào?

## 5. Spring MVC, WebFlux và API

### JVM-034 [Middle] Request đi qua filter, security filter chain, `DispatcherServlet`, interceptor, argument resolver, controller và exception handler theo thứ tự nào?

### JVM-035 [Senior] Thiết kế error response cho REST API thế nào để ổn định, traceable và không leak nội bộ; mapping validation/domain/infrastructure error nên đặt ở đâu?

### JVM-036 [Middle] Bean Validation hoạt động ở request DTO và method boundary thế nào; vì sao không nên dùng JPA entity trực tiếp làm API contract?

### JVM-037 [Senior] Spring MVC thread-per-request và WebFlux event loop khác nhau thế nào; blocking JDBC/call trong reactive chain phá throughput ra sao?

### JVM-038 [Senior] Backpressure, cancellation và context propagation trong Reactor hoạt động thế nào; lỗi phổ biến với `subscribe()`, `block()` và MDC là gì?

## 6. Security, configuration và testing Spring

### JVM-039 [Middle] Authentication và authorization khác nhau thế nào; Spring Security lưu `SecurityContext` ở đâu và cần chú ý gì với async/reactive execution?

### JVM-040 [Senior] CSRF, CORS, session fixation và cookie flags bảo vệ các threat khác nhau thế nào; khi nào API bearer-token có thể tắt CSRF an toàn?

### JVM-041 [Senior] Thiết kế JWT validation cần kiểm tra signature, issuer, audience, expiry, algorithm và key rotation thế nào; revoke/logout là trade-off gì?

### JVM-042 [Middle] Externalized configuration và profile trong Spring Boot nên được tổ chức thế nào; precedence, secret và type-safe `@ConfigurationProperties` cần lưu ý gì?

### JVM-043 [Senior] So sánh unit test thuần, slice test và `@SpringBootTest`; context caching, test isolation và Testcontainers ảnh hưởng tốc độ/độ tin cậy ra sao?

### JVM-044 [Senior] Hãy code review test dùng `@MockBean` cho hầu hết dependency: nó có thể bỏ sót wiring, proxy, serialization và transaction bug thế nào; test pyramid nên cân bằng ra sao?

## 7. JPA/Hibernate và persistence

### JVM-045 [Middle] Entity lifecycle/transitions (`transient`, `managed`, `detached`, `removed`) và dirty checking hoạt động thế nào trong persistence context?

### JVM-046 [Senior] N+1 query xuất hiện với lazy/eager association ra sao; phát hiện và xử lý bằng fetch join, entity graph, batch fetch hoặc projection thế nào?

### JVM-047 [Middle] `LAZY` và `EAGER` là contract gì, không phải query plan như thế nào; `LazyInitializationException` phản ánh boundary thiết kế nào?

### JVM-048 [Senior] Optimistic locking với `@Version` và pessimistic locking khác nhau về contention, retry và deadlock; chọn theo invariant/workload thế nào?

### JVM-049 [Senior] Hãy thiết kế `equals()`/`hashCode()` cho JPA entity khi ID được sinh sau persist và entity có proxy; business key và collection membership gây pitfall gì?

### JVM-050 [Senior] JDBC batching của Hibernate bị ảnh hưởng bởi ID generation, flush/clear, ordering và relationship thế nào; cách import hàng triệu dòng mà không phình persistence context là gì?

### JVM-051 [Senior] Cascade và `orphanRemoval` khác nhau thế nào; cấu hình sai trên aggregate lớn hoặc many-to-many có thể xóa dữ liệu ngoài ý muốn ra sao?

## 8. Build, đóng gói và deploy

### JVM-052 [Middle] Maven/Gradle dependency scope/configuration, transitive dependency và lock/convergence ảnh hưởng build reproducibility thế nào?

### JVM-053 [Senior] Fat JAR, layered container image, CDS và native image khác nhau về startup, memory, build time, reflection và khả năng debug ra sao?

### JVM-054 [Senior] JVM trong container cần cấu hình heap, CPU, direct memory và thread thế nào theo cgroup limit; vì sao chỉ đặt `-Xmx` vẫn có thể bị OOMKilled?

### JVM-055 [Senior] Thiết kế graceful shutdown và zero-downtime deploy cho Spring service thế nào: readiness, draining, shutdown timeout, in-flight request, consumer offset và migration tương thích cần phối hợp ra sao?

## 9. Câu hỏi kinh điển bổ sung — Basic đến Senior

### JVM-056 [Basic · ⭐ Rất thường gặp] JDK, JRE và JVM khác nhau ở vai trò/công cụ nào; một ứng dụng Java cần những thành phần gì ở build time và runtime?

### JVM-057 [Basic · ⭐ Rất thường gặp] Khi nào một object đủ điều kiện được garbage collector thu hồi; reference cycle có ngăn GC không và `System.gc()` có bảo đảm collection ngay không?

### JVM-058 [Basic · ⭐ Rất thường gặp] `@Component`, `@Service`, `@Repository` và `@Controller` khác nhau thế nào ngoài ý nghĩa đặt tên; annotation nào có thêm semantics framework đáng chú ý?

### JVM-059 [Basic · ⭐ Rất thường gặp] Component scanning tìm và đăng ký bean ra sao; package đặt sai hoặc có hai bean cùng type gây lỗi injection nào?

### JVM-060 [Basic · ⭐ Rất thường gặp] `@Controller`, `@RestController` và `@ResponseBody` khác nhau thế nào trong Spring MVC?

### JVM-061 [Basic · ⭐ Rất thường gặp] HTTP method GET, POST, PUT, PATCH và DELETE khác nhau về safety/idempotency thế nào; vì sao retry policy phải dựa trên semantics thực tế?

### JVM-062 [Basic · ⭐ Rất thường gặp] JPA, Hibernate và Spring Data JPA là gì, mỗi lớp chịu trách nhiệm nào và repository abstraction có làm biến mất persistence concern không?

### JVM-063 [Middle · Thường gặp] Thread Context ClassLoader và `ServiceLoader` giúp framework/plugin tìm implementation ra sao; điều gì hỏng khi task chạy trong container hoặc executor với context loader sai?

### JVM-064 [Middle · ⭐ Rất thường gặp] Spring chọn dependency khi có nhiều bean cùng interface theo type, tên, `@Primary` và `@Qualifier` ra sao; inject collection khác inject một bean thế nào?

### JVM-065 [Middle · ⭐ Rất thường gặp] Prototype/request-scoped bean được inject vào singleton có lifetime thực tế thế nào; khi nào cần scoped proxy hoặc `ObjectProvider`?

### JVM-066 [Middle · ⭐ Rất thường gặp] Servlet Filter, Spring MVC HandlerInterceptor và Spring AOP phù hợp ba loại cross-cutting concern nào; boundary và khả năng thấy request/method khác nhau ra sao?

### JVM-067 [Middle · ⭐ Rất thường gặp] Transaction context của Spring có tự truyền qua `@Async`, executor hoặc thread mới không; đặt async boundary sai gây partial commit hoặc query ngoài transaction thế nào?

### JVM-068 [Middle · ⭐ Rất thường gặp] `@PathVariable`, `@RequestParam`, `@RequestBody` và `HttpMessageConverter` phối hợp binding request ra sao; lỗi parse khác lỗi Bean Validation thế nào?

### JVM-069 [Middle · Thường gặp] PUT và PATCH nên được thiết kế thế nào về replace/partial update, idempotency, validation và lost-update protection bằng ETag/version?

### JVM-070 [Middle · ⭐ Rất thường gặp] Trong quan hệ JPA hai chiều, owning side và `mappedBy` quyết định SQL/update foreign key thế nào; vì sao phải đồng bộ cả hai phía trong memory?

### JVM-071 [Senior · Thường gặp] JVM báo `OutOfMemoryError: unable to create native thread` dù heap còn trống: hãy điều tra thread count, `-Xss`, OS/cgroup PID-memory limit và nguồn tạo thread thế nào?

### JVM-072 [Senior · Thường gặp] `@TransactionalEventListener` ở các phase khác nhau có guarantee gì; vì sao side effect `AFTER_COMMIT` thất bại vẫn cần outbox hoặc retry bền vững?

### JVM-073 [Senior · ⭐ Rất thường gặp] Thiết kế POST idempotent trong Spring REST bằng `Idempotency-Key` thế nào để xử lý concurrent duplicate, payload mismatch, response replay, TTL và transaction boundary?

### JVM-074 [Senior · ⭐ Rất thường gặp] JPQL/native bulk update bỏ qua persistence context và entity callback/version ra sao; làm thế nào tránh managed entity stale hoặc lost update sau bulk operation?

### JVM-075 [Senior · Thường gặp] Test Spring mặc định rollback transaction có thể che commit-time constraint, `AFTER_COMMIT` listener hoặc outbox bug thế nào; xây test nào để quan sát đúng production boundary?
