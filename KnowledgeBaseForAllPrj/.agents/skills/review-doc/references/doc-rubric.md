# Documentation review rubric

Check: alignment with implementation and decisions; prerequisites and safe examples; terminology and cross-page consistency; version/freshness metadata; provenance and citations; links and navigation; accessibility and audience fit; ownership and next action.

Report defects as severity, page and section, incorrect or missing claim, authoritative evidence, consequence, and proposed correction. Keep optional style suggestions separate.

Coverage must list reviewed pages, sources checked, links or examples executed, and anything unavailable.
