# Retrieval rubric

Report Recall@k, Precision@k, MRR, nDCG@k, evidence-set coverage, duplicate rate, authorized-candidate rate, stale/superseded hit rate, latency and index version. Break down by exact lookup, semantic, multi-hop/global, long-document and negative/abstain queries.

Never compare retrievers using answer style alone. Freeze corpus version, filters, query set and relevance judgments; include confidence intervals where sample size permits.
