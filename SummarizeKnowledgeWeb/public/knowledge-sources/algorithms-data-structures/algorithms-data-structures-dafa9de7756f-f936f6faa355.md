## Checklist sau mỗi câu coding

- [ ] Tôi nhắc lại đề và xác nhận input/output.
- [ ] Tôi hỏi constraints có ảnh hưởng đến thuật toán.
- [ ] Tôi nêu baseline trước khi tối ưu.
- [ ] Tôi phát biểu invariant/state definition rõ ràng.
- [ ] Code biên dịch và không phụ thuộc state ẩn.
- [ ] Tôi phân tích time và auxiliary space chính xác.
- [ ] Tôi test input rỗng/tối thiểu, duplicate, biên số và case xấu.
- [ ] Tôi có thể nêu vì sao một cách tiếp cận phổ biến khác bị sai/chậm.

## Readiness gate

- [ ] Hai lần liên tiếp cách nhau ≥ 7 ngày đạt ≥ 90% ở các module 01, 02, 03 và 05.
- [ ] Cổng phủ `CG01–CG03` đạt 3/3 trong cả hai lần làm Quiz 05.
- [ ] Hai mock liên tiếp đạt ≥ 90/100 mà không xem đáp án.
- [ ] Không dùng gợi ý mức 2/3 trong ba mock gần nhất.
- [ ] Không lặp lỗi complexity hoặc bỏ edge case trong 7 ngày.
- [ ] Có thể code BFS, DFS, binary search, union-find và một khung DP từ file trống.
- [ ] Có thể giải thích trade-off bằng lời, không chỉ đưa code.

Nếu chưa đạt gate, chọn **một** hàng thấp nhất trong ma trận kỹ năng, ôn và retest có chủ đích; không cần làm lại toàn bộ ngay.
