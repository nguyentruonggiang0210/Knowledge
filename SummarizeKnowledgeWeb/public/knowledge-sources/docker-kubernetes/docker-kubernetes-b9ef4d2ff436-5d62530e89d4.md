# Mục lục bài học

Hai track được sắp theo dependency; hãy học Docker trước phần Kubernetes workload. Các link chi tiết nằm trong index của từng track:

- [Docker deep-dive](Docker/README.md)
- [Kubernetes deep-dive](Kubernetes/README.md)

## Cách hoàn thành một lesson

1. Đọc mục tiêu và tự trả lời phần “khi nào dùng/không dùng”.
2. Vẽ lại sơ đồ bằng trí nhớ.
3. Gõ lại sample tối thiểu một lần; không chỉ chạy file có sẵn.
4. Thực hiện happy path rồi ít nhất hai failure drill.
5. Làm quiz liên quan trong [QA](../QA/README.md).
6. Ghi bằng chứng vào [coverage checklist](../KNOWLEDGE-CHECKLIST.md).

Mỗi command cần được hiểu theo ba câu hỏi: nó gọi API nào, thay đổi state gì, và quan sát/rollback bằng cách nào.
