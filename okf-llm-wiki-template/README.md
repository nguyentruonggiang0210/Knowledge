# OKF + LLM Wiki — Software/Dev Template

A practical knowledge bundle for software engineering projects using Open Knowledge Format (OKF) v0.2.

Goals:
- one durable Markdown document per knowledge unit
- YAML frontmatter for machine-readable metadata
- explicit provenance, verification and freshness
- progressive disclosure through index.md
- Git-friendly history
- safe agent workflow for ingesting, updating and validating knowledge

This template deliberately uses a project-specific taxonomy (`concepts`, `architecture`,
`decisions`, `runbooks`, `services`, `apis`, `data`, `people`, `sources`) while remaining
compatible with OKF's permissive directory model.
